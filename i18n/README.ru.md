В macOS Tahoe удалён Launchpad, а новый интерфейс Apps не удовлетворяет потребности пользователей и не использует Bio GPU Mac в полную силу. Apple при этом не предоставляет возможности вернуться к прежнему опыту. AppBoard пытается решить эту проблему.

*AppBoard построен на основе [LaunchNext](https://github.com/RoversX/LaunchNext) и [LaunchNow](https://github.com/ggkevinnnn/LaunchNow) (автор: ggkevinnnn) — огромное спасибо оригинальным проектам! ❤️*

*LaunchNext и LaunchNow распространяются под лицензией GPL 3, AppBoard следует тем же условиям.*

⭐ Пожалуйста, поставьте звезду [LaunchNext](https://github.com/RoversX/LaunchNext) и оригинальному [LaunchNow](https://github.com/ggkevinnnn/LaunchNow)!


## Что предлагает AppBoard
- ✅ **Идентичный опыт классическому LaunchPad** - Мы постарались максимально воссоздать поведение старого LaunchPad: долгое нажатие с дрожанием для удаления, перетаскивание для объединения однотипных приложений в папку и многое другое.
- ✅ **Импорт из старого LaunchPad в один клик** - Напрямую читает родную SQLite-базу Launchpad и восстанавливает папки, позиции и компоновку
- ✅ **Ручная организация приложений** - Перемещайте приложения, создавайте папки и сохраняйте удобную раскладку
- ✅ **Два режима рендеринга** - `Legacy Engine` для совместимости, `Next Engine + Core Animation` для лучшего опыта
- ✅ **Компактный и полноэкранный режимы** - Настройки сохраняются раздельно
- ✅ **Работа с клавиатурой в первую очередь** - Быстрый поиск, навигация и запуск
- ✅ **Hot Corner и нативные жесты** - Несколько способов глобального вызова
- ✅ **Перетаскивание приложений прямо в Dock** - Доступно в движке Core Animation
- ✅ **Центр обновлений с Markdown-описаниями релизов** - Более насыщенный опыт обновления
- ✅ **Инструменты резервного копирования и восстановления** - Безопасный экспорт и восстановление
- ✅ **Поддержка доступности и контроллеров** - Улучшена голосовая обратная связь и навигация геймпадом
- ✅ **Многоязычная поддержка** - Широкое покрытие локализаций

## Что забрал macOS Tahoe

- ❌ Нельзя настраивать организацию приложений
- ❌ Нельзя создавать пользовательские папки
- ❌ Нет настройки перетаскиванием
- ❌ Нет визуального управления приложениями
- ❌ Принудительная группировка по категориям

## Хранение данных

Данные приложения сохраняются здесь:

```text
~/Library/Application Support/AppBoard/Data.store
```

## Интеграция с нативным Launchpad

AppBoard может напрямую читать системную базу Launchpad:

```bash
/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db
```

## Установка

### Системные требования

- macOS 26 (Tahoe) или новее
- Процессор Apple Silicon или Intel
- Xcode 26 (для сборки из исходников)

### Сборка из исходников

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/MiniMindX/AppBoard.git
   cd AppBoard
   ```

2. **Откройте в Xcode**
   ```bash
   open AppBoard.xcodeproj
   ```

3. **Соберите и запустите**
   - Выберите целевое устройство
   - Нажмите `⌘+R` для сборки и запуска
   - Или `⌘+B` для сборки без запуска

### Сборка из командной строки

Сборка делится на два шага: сначала убедиться, что SwiftUpdater собран (нужно только при первой сборке или после clean), затем собрать само приложение.

**1. Одноразовая предсборка SwiftUpdater**

Нужна только при первом клонировании или после удаления UpdaterScripts/SwiftUpdater/.build/:

```bash
cd UpdaterScripts/SwiftUpdater
swift build --configuration release --arch arm64 --arch x86_64 --product SwiftUpdater
cd ../../
```
Результат окажется в `UpdaterScripts/SwiftUpdater/.build/apple/Products/Release/SwiftUpdater`, а `Run Script Phase` основного `App` автоматически его скопирует.

**2. Сборка основного приложения:**
- Debug-сборка (повседневная):
```bash
xcodebuild -project AppBoard.xcodeproj -scheme AppBoard -configuration Debug -destination 'platform=macOS' build
```
Результат: `~/Library/Developer/Xcode/DerivedData/AppBoard-<hash>/Build/Products/Debug/AppBoard.app`

- Release-сборка:
```bash
xcodebuild -project AppBoard.xcodeproj -scheme AppBoard -configuration Release -destination 'platform=macOS' build
```

- Релизная упаковка (Release + zip + checksum):
```bash
./scripts/release.sh
```

Скрипт выполняет `clean build` в `Release`, упаковывает `AppBoard.app` в `AppBoard<версия>.zip` в `Build/dist/` и создаёт `checksums.txt`.

- Сборка прямо в Xcode
Откройте `AppBoard.xcodeproj`, `Cmd+B` для сборки, `Cmd+R` для запуска. `Xcode` автоматически использует `AppBoard scheme`. `SwiftUpdater` всё равно нужно один раз собрать командой выше.

**3. Универсальный бинарник (Intel + Apple Silicon):**
```bash
  xcodebuild -project AppBoard.xcodeproj -scheme AppBoard -configuration Release \
    -destination 'generic/platform=macOS' \
    ARCHS="arm64 x86_64" \
    ONLY_ACTIVE_ARCH=NO \
    clean build
```

## Использование

### Быстрый старт

1. AppBoard сканирует все установленные приложения при первом запуске
2. Импортируйте раскладку старого Launchpad или начните с пустой
3. Организуйте приложения через поиск, клавиатуру, перетаскивание и папки
4. Настройте движок, режим раскладки, способы вызова и автоматизацию в Настройках

### Импорт вашего Launchpad

1. Откройте Настройки
2. Нажмите **Import Launchpad**
3. Существующая раскладка и папки импортируются автоматически

### Движки и режимы раскладки

- **Legacy Engine** - Сохраняет прежний рендеринг, приоритет совместимости
- **Next Engine + Core Animation** - Рекомендуется. Лучший общий опыт и поддержка новых функций
- **Компактный / Полноэкранный** - AppBoard поддерживает оба режима и хранит их настройки отдельно

## Ключевые возможности

### Активация и ввод

- **Поддержка Hot Corner** - Открывайте AppBoard из настраиваемого угла экрана
- **Экспериментальная поддержка нативных жестов** - Действия pinch / tap четырьмя пальцами
- **Глобальные горячие клавиши** - Открывайте AppBoard из любого места
- **Перетаскивание в Dock** - В движке Core Animation приложение передаётся напрямую в macOS Dock

### Опыт обновлений

- **Центр обновлений в приложении** - Проверка обновлений без выхода из приложения
- **Markdown-описания релизов** - Богатые release notes прямо в Настройках
- **Современный Notification API** - Совместимость с обновлённой системой уведомлений macOS

### Резервные копии и восстановление

- Создание и восстановление резервных копий из Настроек
- Более надёжный экспорт резервных копий
- Безопасная работа с временными файлами и очисткой

### Доступность и навигация

- **Голосовая обратная связь** - Озвучивание имён приложений и папок при навигации
- **Поддержка контроллеров** - Управляйте AppBoard и папками с помощью геймпада
- **Клавиатура в первую очередь** - Быстрый поиск и навигация без мыши

## Производительность и стабильность

- Умное кеширование иконок для плавной работы
- Ленивая загрузка и фоновое сканирование для больших библиотек
- Лучшая синхронизация состояния Настроек и навигации
- Повышенная надёжность обновлений, экспорта резервных копий и восстановления жестов
